# Helfy Tracker - easy steps

## Put it on GitHub (5 steps)
1. Go to github.com, sign in, tap the + (top right) > New repository.
2. Name it helfy-tracker, choose Public, tap Create repository.
3. Tap "uploading an existing file", drag in ALL files from this folder (index.html, sw.js, manifest.json, icon.png), tap Commit changes.
4. Go to Settings > Pages. Under Branch choose main, tap Save.
5. Wait 1 minute. Your app link appears at the top of that page. Open it on your phone.

## Install on phone
Open the link > Allow location > menu > Add to Home Screen.

## Use
- Tap the ◐ button for black / white theme.
- Tap the map or search a place > Guide me here.
- It says LEFT, RIGHT, FORWARD or MISS and shows distance and minutes.
- Before going offline, tap "Offline map" once.
